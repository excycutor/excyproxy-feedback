## 🇷🇺 Русский

Официальный трекер обратной связи для расширения **ExcyProxy Switcher**.

Здесь вы можете сообщить об ошибке, предложить новую функцию или задать вопрос.

### 🐛 Сообщить об ошибке

1. Убедитесь, что такой проблемы ещё нет в [открытых issues](../../issues)
2. Создайте [новый issue](../../issues/new) с меткой `bug`
3. Опишите проблему:
   - Что произошло?
   - Что ожидалось?
   - Версия расширения и браузера
   - Шаги для воспроизведения

### 💡 Предложить идею

1. Проверьте, не предлагал ли кто-то подобное в [issues](../../issues)
2. Создайте [новый issue](../../issues/new) с меткой `enhancement`
3. Опишите:
   - Какую проблему это решит?
   - Как вы видите реализацию?

## 🇬🇧 English

Official feedback tracker for **ExcyProxy Switcher** extension.

Here you can report bugs, suggest features, or ask questions.

### 🐛 Report a Bug

1. Check if the issue already exists in [open issues](../../issues)
2. Create a [new issue](../../issues/new) with the `bug` label
3. Describe the problem:
   - What happened?
   - What was expected?
   - Extension and browser version
   - Steps to reproduce

### 💡 Suggest a Feature

1. Check if someone already suggested it in [issues](../../issues)
2. Create a [new issue](../../issues/new) with the `enhancement` label
3. Describe:
   - What problem does it solve?
   - How do you envision it?

**Privacy Policy

ExcyProxy Switcher does not collect, store, transmit, or share any personal or user data.

All extension settings, including proxy configurations and authentication credentials, are stored locally on the user’s device using Chrome storage APIs and are never transmitted to external servers.

The extension does not use analytics, tracking, telemetry, or advertising technologies.

Network requests are processed solely to apply user-defined proxy settings and routing rules. The content of web traffic is not inspected, logged, or recorded.

ExcyProxy Switcher does not sell, share, or transfer user data to third parties.
